# بررسی مقدماتی آمادگی انتشار نکساچت در راست‌چین

تاریخ: ۲۰۲۶/۱۰/۲۶ — مبنا: نسخهٔ ۱.۷.۵ و تغییرات باز PR 36.

## نتیجه

آمادگی فنی اولیه وجود دارد، اما «تأیید کامل برای انتشار در راست‌چین» قابل اعلام نیست. این بررسی، کنترل مقدماتی کد و بسته‌بندی است؛ جایگزین ارزیابی کنترل کیفیت مارکت یا آزمون دستی روی هاست مقصد نیست.

## اصلاحات همین درخواست

- لینک گزارش مشکل در About به `https://dbsstudio.ir/issues` منتقل شد. صفحه هنوز طبق تصمیم مالک ساخته نشده است؛ قبل از تحویل به مشتری باید قابل استفاده باشد.
- لیست تغییرات از فایل همراه افزونه خوانده می‌شود و داخل About باز می‌شود؛ نیازی به دسترسی به مخزن خصوصی یا درخواست اینترنتی ندارد. خروجی یادداشت‌ها به صورت متن escape می‌شود.
- آدرس گزارش خطای فایل ترجمه و مولد POT نیز به وب‌سایت تغییر کرد؛ تولید مجدد ترجمه آن را به گیت‌هاب برنمی‌گرداند.
- دستور دانلود در readme مشتری به محل خرید منتقل شد. سیاست گزارش امنیتی نیز وابستگی به مخزن خصوصی ندارد.
- لینک‌های عمومی صاحبان فونت‌ها در notices حذف نشده‌اند؛ آن‌ها نشانی مخزن خصوصی محصول یا مسیر پشتیبانی مشتری نیستند.

## یافته‌های انتشار

| موضوع | وضعیت و اقدام لازم |
|---|---|
| پشتیبانی خریداران راست‌چین | مهم: مادهٔ ۱۵ قوانین عمومی، ارتباط رسمی خریدار و فروشنده را به تیکت راست‌چین محدود می‌کند. `/issues` طبق درخواست مالک حفظ شده است؛ پیش از ارسال محصول باید کاربرد آن به عنوان دریافت بازخورد عمومی با کنترل کیفیت مارکت روشن شود. جایگزین کردن تیکت رسمی با این صفحه تأیید نشده است. |
| آزمون روی هاست | مادهٔ ۱۳ محیط تست لینوکسی با وردپرس و قالب پیش‌فرض را توصیف می‌کند. CI شامل آزمون یکپارچهٔ وردپرس/MySQL است؛ آزمون دستی نصب، ارتقا، فارسی، موبایل و اتصال واقعی سرویس روی هاست هدف هنوز باید انجام شود. |
| اطلاعات صفحه فروش | هزینه و کلید API سرویس هوش مصنوعی، نیاز به اینترنت خروجی هاست، محدودیت دسترسی سرویس خارجی و اختیاری بودن سرویس پیامک/پیام‌رسان باید پیش از خرید روشن باشد. readme ارتباطات خارجی را توضیح می‌دهد، اما متن صفحهٔ فروش و دمو در این بررسی موجود نبود. |
| پیش‌نیازها | هدر افزونه WordPress 5.6+ و PHP 7.4+ اعلام می‌کند؛ صفحهٔ About وضعیت mbstring و OpenSSL را بررسی می‌کند. ZipArchive برای Word و zlib برای بعضی PDFها نیاز است. این تفاوت‌ها باید در صفحه فروش ذکر شوند. |
| راهنما | راه‌انداز پنج‌مرحله‌ای، دستور نصب در readme و راهنمای فارسی دارویی موجودند. راهنمای عمومی فارسی برای همهٔ ماژول‌ها در فایل‌های بررسی‌شده وجود نداشت؛ افزودنش برای کاهش ابهام مشتری پیشنهاد می‌شود، نه به عنوان شرط قطعی منتشرشدهٔ مارکت. |
| مجوز فونت‌ها | `assets/fonts/LICENSE.txt` انتساب و لینک مجوزها را دارد، اما متن کامل OFL و Apache 2.0 در این پوشه دیده نشد. پیش از توزیع تجاری، همراه‌بودن متن کامل مجوز و notice متناظر فایل‌های واقعی فونت بررسی و تکمیل شود. |
| لایسنس و بروزرسان مارکت | در بستهٔ فعلی لایسنس/بروزرسان اختصاصی راست‌چین دیده نشد؛ readme هم نبود license check و update ping را اعلام می‌کند. الزام دقیق اتصال SDK برای این محصول از منابع عمومی بررسی‌شده احراز نشد؛ بدون مشخصات رسمی یا شناسه محصول، یکپارچه‌سازی حدسی اضافه نشده است. |
| بسته‌بندی | سازندهٔ ZIP از allowlist استفاده می‌کند، پوشهٔ استاندارد `nexachat-ai/` می‌سازد و فایل‌های توسعه و اسناد داخلی را کنار می‌گذارد. verifier مسیرها، فایل‌های لازم و الگوهای credential را بررسی می‌کند. تأیید بستهٔ واقعی همین تغییرات باید با job بسته‌بندی CI انجام شود. |
| امنیت و حریم خصوصی | در قسمت‌های نمونه‌برداری‌شده، کلیدها با AES/HMAC ذخیره می‌شوند، HTTP عمومی امن و redirect محدود است، REST مدیریتی capability می‌خواهد و حذف داده‌ها opt-in است. این شواهد، ممیزی جامع امنیتی همهٔ قابلیت‌ها یا تضمین بی‌باگ‌بودن نیست. |

## محدودهٔ بررسی

About و گزارش پشتیبانی، readme، هدر افزونه، تنظیمات و رمزگذاری، HTTP، REST، رندر frontend و فونت‌ها، uninstall، اسکریپت‌های بسته‌بندی، فهرست فایل‌های مخزن و CI بررسی شدند. آزمون دستی مرورگر، اتصال واقعی AI، دمو و قرارداد خصوصی فروشندگان در این مرحله بررسی نشده‌اند.

نسخه تغییر نکرده است. تا دستور صریح مالک هیچ مرج، تگ یا ریلیزی نباید ساخته شود.
