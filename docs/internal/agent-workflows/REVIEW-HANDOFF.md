# پرامپت بازبینی و تکمیل کار ایجنت

همراه این فایل: چارچوب مشترک، پرامپت فاز با SELECTED_IDS پرشده، خروجی ایجنت و diff یا commit.

به‌عنوان بازبین فقط موارد منتخب را بررسی کن. اول base/head و محدوده را تطبیق بده؛ از «تکمیل» برای اضافه‌کردن ایده‌های انتخاب‌نشده استفاده نکن.

۱. آیا خواستهٔ کاربر کامل و استفاده ساده‌تر/همان‌قدر ساده مانده؟ تنظیمات داخلی وارد تجربه عادی نشده؟
۲. آیا از کد و ماژول فعلی استفاده شده؟ وابستگی، gate سمت سرور، حالت خاموش، حفظ داده و روشن‌شدن دوباره درست است؟
۳. آیا مجوز، مالکیت، هزینه، retry و خطا در مسیر واقعی درست‌اند؟ موفقیت جعلی یا منبع/عدد ساختگی وجود ندارد؟
۴. آیا ظاهر فارسی/RTL/موبایل، preview و رفتار موبایل مورد تأیید حفظ شده؟
۵. تست‌ها را فقط به اندازهٔ تغییر و شکاف باقی‌مانده بازبینی/اجرا کن. mock، SKIP و نبود محیط را موفقیت واقعی معرفی نکن.
۶. نقص مرتبط را رفع کن؛ تغییر پرریسک یا تصمیم تازه را با یک سؤال واضح متوقف کن. تغییرات دیگران را بازنویسی نکن.
۷. Version، tag، release و merge بدون دستور مالک دست‌نخورده بمانند. مستندات کنار کد منتخب به‌روز باشند.

خروجی نهایی کوتاه: قبول/نیازمند اصلاح، موارد تکمیل‌شده، آزمون و محدودیت، گام تست عملی مالک. ایراد با مسیر/خط و اثر واقعی؛ از اخطار نظری نامرتبط پرهیز کن.
