# گزینه‌های تکمیلی از مستندات مخزن؛ انتخاب نشده

این موارد هنگام بررسی تازهٔ مستندات پیدا/تفکیک شدند. برخی زیرمجموعهٔ کلی ردیف‌های ۹۱گانه‌اند، اما در آن نقشه صریح نبودند؛ برای گم‌نشدن اینجا آمده‌اند. **هیچ‌کدام دامنهٔ پرامپت فاز را خودکار زیاد نمی‌کنند.** اگر سعید انتخاب کند، قبل از اجرا شناسه و معیار پذیرش مستقل به پرامپت فاز مربوط اضافه می‌شود.

این فهرست، ادعای نیاز به ساخت همهٔ گزینه‌ها یا وضعیت قطعی فعلی نیست. اصلاحات تاریخی که در مستندات رفع‌شده ثبت‌اند، به‌عنوان کار جدید تکرار نشده‌اند.
