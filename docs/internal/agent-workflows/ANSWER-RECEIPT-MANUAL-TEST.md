# تست عملی مالک — AR-01

این راهنما برای نصب آزمایشی است؛ نسخه/انتشار عمومی لازم نیست. کد branch PR #44 را استفاده کنید؛ بستهٔ قابل نصب را فقط با builder و verifier موجود بسازید. فایل‌های تغییرکرده با نسخهٔ ثابت ممکن است در کش مرورگر/CDN قدیمی بمانند؛ کش سایت/مرورگر محیط تست را پاک کنید.

۱. پیش از فعال‌کردن ماژول، رفتار چت مثل قبل است و نشان جدیدی ندارد.
۲. در «ماژول‌ها»، «رسید پاسخ» را روشن کنید؛ گزینهٔ پیچیدهٔ دیگری لازم نیست.
۳. در حالت فقط بانک پاسخ، یک سؤال با پاسخ ثبت‌شده بپرسید: «از پاسخ‌های ثبت‌شده» و جزئیات بازشونده ببینید؛ تضمین تأیید یا شناسهٔ خصوصی FAQ نباید نمایش داده شود.
۴. در حالت AI، پاسخ با/بدون منبع عمومی را بررسی کنید؛ نشان AI مدرک درستی همهٔ ادعاها نیست. بدون منبع باید همین نبود منبع صادقانه اعلام شود.
۵. پاسخ یکسانِ بدون تاریخچه را با cache دوباره امتحان کنید: «پاسخ ذخیره‌شده» با زمان اصلی، و برای cache قدیمی بدون metadata، منشأ ناموجود؛ نه منبع تازهٔ ساختگی.
۶. show_sources را خاموش کنید: هیچ عنوان یا URL داخل رسید نمایش داده نشود. صفحهٔ منبع را خصوصی/رمزدار کنید: پیوند cacheشده هم نباید نمایش داده شود.
۷. ماژول را خاموش و دوباره روشن کنید؛ متن پاسخ/تنظیمات و داده حفظ شود. History خاموش هم receipt را از کار نمی‌اندازد و logging اجباری نمی‌شود.
۸. موبایل با کیبورد، فارسی/انگلیسی، متن بلند و Tab/Enter را بررسی کنید؛ چت همچنان پنجرهٔ شناور باشد.
۹. پس از بازکردن گفتگوی قبلی، رسیدی که در History ذخیره نشده نباید بازسازی یا جعل شود. پیام‌رسان‌ها نباید JSON خام receipt نشان دهند.

گزارش بازخورد: branch/commit، ماژول و حالت پاسخ، گام تکرار، انتظار/نتیجه و screenshot بدون اطلاعات شخصی. کلید API نفرستید.
