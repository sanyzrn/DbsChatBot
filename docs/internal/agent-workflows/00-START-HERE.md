# بستهٔ پرامپت‌های توسعهٔ واژو

ترتیب استفاده: **چارچوب ثابت → پرامپت همان فاز → اجرای موارد منتخب → بازبینی و تکمیل**.
این بسته فقط فایل‌های راهنماست؛ هیچ تغییر کد، تنظیمات، merge یا انتشار انجام نشده است.

## محتوا

- `01-Vazho-Development-Framework.md`: چارچوب مشترک؛ همیشه همراه پرامپت.
- `PHASE-00-Agent-Prompt.md`: بررسی موجودی و گزارش، فقط خواندنی؛ آمادهٔ ارائه به ایجنت.
- `PHASE-01` تا `PHASE-09`: پرامپت جدا به ترتیب فازهای نقشه. همهٔ شناسه‌های فاز آمده‌اند، اما `SELECTED_IDS = []` است و مجوز ساخت نیست.
- `Vazho-Selection-Catalog.md`: نقشهٔ مرجع ۹۱ مورد و وابستگی‌ها؛ ضمیمهٔ فاز صفر و مرجع انتخاب فازهای بعد.
- `02-Repository-Review.md`: نتیجهٔ تطبیق مستندات، استثناها و اختلاف‌های نسخه‌ها.
- `REPO-SUPPLEMENT.md`: ایده‌های افزودهٔ مستندات مخزن؛ هیچ‌کدام انتخاب یا به دامنهٔ اجرای فاز اضافه نشده‌اند.
- `REVIEW-HANDOFF.md`: پرامپت بررسی و تکمیل خروجی ایجنت توسط بازبین.

## اولین نوبت

به ایجنت بده: **چارچوب + پرامپت فاز صفر + کاتالوگ مرجع** و دسترسی به مخزن. خروجی باید گزارش وضعیت باشد، نه تغییر کد. سپس گزارشش را همراه branch/commit/diff در صورت وجود برای بازبین بفرست. برای فاز صفر نباید diff کد وجود داشته باشد.

## نوبت‌های بعد

۱. سعید شناسه‌ها را انتخاب می‌کند. مثال: `SELECTED_IDS = ["01-04", "01-05"]`.
۲. چارچوب و فقط پرامپت همان فاز را بده؛ فایل منتخب را با مقادیر واقعی جایگزین کن. صرف ارسال ZIP به معنی «همه را بساز» نیست.
۳. پیش‌فرض هر نوبت حداکثر سه مورد؛ مراحل وابسته به ترتیب و با scope کوچک انجام شوند.
۴. اجازهٔ push/PR فقط اگر مالک خواست در ورودی روشن شود. merge، تغییر نسخه و انتشار همچنان پیش‌فرض ممنوع‌اند.
۵. برای تست عملی، فقط در صورت درخواست `BUILD_LOCAL_TEST_ZIP=true`؛ این گزینه مجوز انتشار نیست.
۶. گزارش و patch را با `REVIEW-HANDOFF.md` برای بازبین بیاور؛ انتخاب فاز بعد پس از نتیجهٔ این نوبت.

شمارهٔ فازها زمان‌بندی اجباری نیست. لازم نیست همهٔ موارد یک فاز ساخته شوند؛ پیش‌نیاز واقعیِ آیتم منتخب باید رعایت شود.

## تصمیم‌های پیش‌فرض تغییرنکرده

کد سالم حفظ می‌شود؛ توسعهٔ تدریجی و ماژولار؛ نام Vazho؛ بدون مهاجرت صرفاً برای نام قبلی؛ بدون عجله برای انتشار. فاز ۹ امکان‌سنجی است و پیش‌فرض اجازهٔ پیاده‌سازی نمی‌دهد.

این بسته اکنون در `docs/internal/agent-workflows/` است. برای وضعیت فعلی از `STATUS.md` و `CONTINUE-HERE.md` شروع کن؛ راهنمای اولین نوبتِ بالا مربوط به شروع اولیهٔ بسته است، نه مجوز تکرار ممیزی یا اجرای مرحلهٔ تازه.
