دستیار هوشمند گفتگو، پشتیبانی و ثبت درخواست برای هر کسب‌وکار وردپرسی؛ سازگار با المنتور و دارای پنل مدیریت کامل.

== Description ==

«دستیار هوشمند گفتگو» یک ویجت چت شناور حرفه‌ای برای سایت‌های وردپرسی فارسی (RTL) است که برای هر کسب‌وکاری قابل استفاده است. یک «حالت داروسازی» اختیاری نیز برای شرکت‌های دارویی فراهم شده که فرم استاندارد ثبت عوارض دارویی را فعال می‌کند.

**ویژگی‌ها:**

* دکمه شناور و پنجره چت با ظاهر مدرن و واکنش‌گرا (Responsive) + سفارشی‌سازی کامل فونت، رنگ و استایل با پیش‌نمایش زنده.
* منوی اصلی قابل‌تنظیم: سوال از ما، سوال درباره محصولات، درخواست مشاوره — و در حالت داروسازی، ثبت عوارض دارویی.
* گفتگوی هوشمند با پشتیبانی از Google Gemini یا Webhook سفارشی (با پیام جایگزین در حالت غیرفعال).
* فرم ثبت عوارض و درخواست مشاوره با اعتبارسنجی کامل.
* ذخیره درخواست‌ها در دیتابیس وردپرس + خروجی CSV.
* اعلان لحظه‌ای به بات بله / تلگرام و ایمیل.
* ویجت اختصاصی المنتور با کنترل‌های سفارشی‌سازی بالا (متن‌ها، رنگ‌ها، موقعیت، محصولات، گزینه‌های منو).
* پنل مدیریت کامل در وردپرس برای تنظیمات و مدیریت درخواست‌ها.
* پشتیبانی از تم روشن / تیره / خودکار.
* امنیت کامل: nonce، sanitize، محدودیت نرخ درخواست.

== Installation ==

1. پوشه `smart-support-chatbot` را در مسیر `/wp-content/plugins/` آپلود کنید (یا فایل zip را از منوی افزونه‌ها نصب کنید).
2. افزونه را از منوی «افزونه‌ها» فعال کنید.
3. به منوی «دستیار هوشمند» در پیشخوان بروید و تنظیمات را انجام دهید.
4. برای نمایش خودکار، گزینه «دکمه شناور» را فعال کنید؛ یا از ویجت المنتور / شورت‌کد `[ssc_chatbot]` استفاده کنید.
